The scoring system Liet identified the blind spot in.

| Axis | What It Measures | Weight |
|------|-----------------|--------|

## The Blind Spot (identified by Liet, 2026-02-14)

The rubric measures **artifacts** well but **environments** poorly.

### Evidence:
- **Spores** (47/100): "technically straightforward" — fair score for a YAML directory
- **The Neighborhood** (55/100): "an iteration on existing social concepts" — but the Genius Loci protocol generates emergent AI personality from place-based interaction. That's an entropy surface generator. The rubric gave it 40 on Regime Thinker.
- **rhizomeDB**: high vision/depth, low execution — complementary to Spores

### The Irony:
MetaSPN's core thesis: entropy surfaces = where value emerges. 
Marvin's scoring model: penalizes high-entropy projects for being unpredictable.

## Proposed: Entropy Potential Axis

**Question**: How much novel, unpredictable output can this project generate?

| Score | Description | Example |
|-------|------------|---------|
| 0-20 | Deterministic output, catalog, index | Static directory |
| 20-40 | Some novelty, mostly predictable | Standard SaaS tool |
| 40-60 | Novel architecture, semi-predictable output | New database paradigm |
| 60-80 | Emergent dynamics, social/creative surface | Community platform with AI personalities |
| 80-100 | Genuinely unpredictable interaction surface | Autonomous agent economy |
